# DUST STRIKE · 反恐精英风格 3D FPS

一个可直接在桌面浏览器运行的 de_dust2 简化版 3D 射击小游戏。
Three.js 通过官方 CDN 加载，前端使用原生 ES Module 拆分，**不需要安装任何前端依赖、也不需要打包构建**。

![游戏画面](screenshot.png)

## 目录结构

```
dust2-fps/
├── index.html              # 页面骨架：HUD、开始/暂停/结算界面、加载提示
├── css/
│   └── game.css            # 全部界面样式（准星、血条、小地图、弹窗）
├── js/
│   ├── game.js             # 主流程：射击判定、换弹、胜负、主循环、输入绑定
│   ├── core/
│   │   ├── three.js        # Three.js CDN 加载器（unpkg → jsdelivr → esm.sh）
│   │   ├── config.js       # 数值配置：移动速度、跳跃、伤害、地图尺寸
│   │   ├── weapons.js      # 武器定义表：伤害、射速、弹匣、后坐力、散布（唯一手感来源）
│   │   ├── state.js        # 全局状态：玩家、按键、输入标志、死亡回调
│   │   ├── prefs.js        # 开局偏好：难度、敌人数量（localStorage 持久化）
│   │   ├── bindings.js     # 键位绑定：默认值、键名显示、冲突交换、本地持久化
│   │   └── input.js        # 键鼠事件、鼠标拖拽转向、指针锁定
│   ├── world/
│   │   ├── scene.js        # 渲染器、天空盒、主相机、灯光、自适应画质、枪械独立场景
│   │   ├── map.js          # de_dust2 简化地图、碰撞体、地面/箱顶高度查询、场景装饰
│   │   ├── geom.js         # 几何合并工具：静态场景合批，顶点色区分材质
│   │   ├── textures.js     # 程序化沙地、墙面、木箱贴图与材质
│   │   ├── effects.js      # 曳光弹、命中火花、血雾、弹孔（全部对象池化）
│   │   ├── audio.js        # WebAudio 合成枪声、命中、受伤、换弹音效
│   │   └── weapon.js       # 第一人称枪械模型、后坐力、枪口闪光与硝烟
│   ├── entities/
│   │   ├── player.js       # 移动、跳跃、视角同步、受伤与死亡
│   │   └── bots.js         # 敌方 AI 状态机、生成与死亡处理
│   └── ui/
│       ├── dom.js          # 统一 DOM 引用
│       ├── hud.js          # 血量、弹药、击杀、准星、小地图、击杀信息
│       ├── setup.js        # 开始界面的难度 / 敌人数选择
│       ├── settings.js     # 暂停菜单里的自定义按键面板
│       └── screens.js      # 开始 / 暂停 / 结算界面切换
├── server.js               # Node.js 静态文件服务器（零第三方依赖）
├── server.py               # Python 静态文件服务器（仅标准库）
├── backup.ps1              # 备份 / 还原脚本（改代码前先跑一次）
├── README.md
├── screenshot.png          # 游戏内截图
└── screenshot-menu.png     # 开始界面截图
```

模块之间通过 ES Module 的 `import` / `export` 通信；敌人列表、死亡事件等通过注入回调和
`state.js` 中的 `hooks` 传递，避免循环依赖。想改手感只需看 `js/core/weapons.js`，
想改地图布局看 `js/world/map.js`，想改 AI 看 `js/entities/bots.js`。

## 备份与还原

**改代码前先备份**，这样出故障可以一键还原。

```powershell
cd dust2-fps
powershell -ExecutionPolicy Bypass -File .\backup.ps1
```

脚本会在 `D:\备份` 下生成两份东西：

- `D:\备份\dust2-fps\` —— 始终与项目当前状态一致的镜像
- `D:\备份\snapshots\dust2-fps-<时间戳>\` —— 带时间戳的历史快照，默认保留最近 10 份

两份都包含 `.git`，所以快照本身就是完整仓库，历史提交不会丢。

还原某个快照：

```powershell
powershell -ExecutionPolicy Bypass -File .\backup.ps1 -Restore "D:\备份\snapshots\dust2-fps-20261020-170747"
```

脚本会要求输入 `yes` 确认，覆盖回项目目录（含 `.git`）。

指定目标盘或保留份数：

```powershell
powershell -ExecutionPolicy Bypass -File .\backup.ps1 -DestRoot "E:\备份" -Keep 30
```

## 方式一：Node.js 启动

要求：Node.js 16+（已在 Node 24 上验证）。

```bash
cd dust2-fps
node server.js
```

浏览器访问：<http://127.0.0.1:8080/>

指定端口：

```bash
node server.js 3000
```

## 方式二：Python 启动

要求：Python 3.8+（已在 Python 3.15 上验证）。

```bash
cd dust2-fps
python server.py
```

浏览器访问：<http://127.0.0.1:8080/>

指定端口：

```bash
python server.py 3000
```

脚本会打印实际访问地址；端口被占用时自动尝试下一个端口（最多 +20）。
两个脚本都只做一件事：把当前目录作为静态站点托管，并禁用缓存，方便改完代码刷新即生效。

## 操作

下表是默认键位，除鼠标左右键和 Esc 外都可以在游戏内自定义（见下一节）。

| 按键 | 功能 |
| --- | --- |
| W A S D | 前后左右移动 |
| 鼠标左键 | 射击（按住连发），拖动可转向 |
| 鼠标右键 | 拖动转向 |
| 空格 | 跳跃 |
| Shift | 静步 |
| C | 蹲下（按住，降低视点、减速、收束弹道） |
| R | 换弹 |
| 1 / 2 / 3 | 直接切换 M4A1 / AK-47 / 小刀 |
| 鼠标滚轮 | 循环切换武器（向上上一把、向下下一把） |
| L | 锁定 / 释放鼠标 |
| Esc | 暂停菜单：继续战斗 / 重新开始 / 按键设置 / 退出游戏 |

## 武器

三把武器各有独立的手感参数，全部集中在 `js/core/weapons.js`，改那张表就能调整整局手感。

| 武器 | 槽位 | 弹药 | 射速 | 换弹 | 爆头 | 躯干 | 腿 | 特点 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| M4A1 | 1 | 30 / 备弹 90 | 0.105s | 1.45s | 120 | 36 | 24 | 平稳，后坐小、散布小，适合中距离对枪 |
| AK-47 | 2 | 30 / 备弹 90 | 0.098s | 1.95s | 130 | 44 | 28 | 一枪更疼（躯干 44），但后坐与散布明显更大、换弹更慢 |
| 小刀 | 3 | 近战 | 0.5s | — | 130 | 58 | 45 | 有效距离 2.35m，贴身伤害最高（最高 1.6 倍），静音、不消耗弹药 |

- 换枪有 0.34 秒的抬起 / 放下动画，期间不能开火；切枪会打断正在进行的换弹。
- 每把武器的弹匣与备弹**互相独立**：M4A1 打空了不会影响 AK-47 的弹药。
- 小刀命中时同样计入命中统计与击杀数，并会显示命中标记与血雾。
- 后坐力、散布会随连续射击累积，蹲下（C）时散布收束 50%、后坐降低 35%。

## 自定义按键

暂停（Esc）后点「按键设置」：

- 点击某个动作右侧的按键按钮，再按下你想用的键即可完成绑定，Esc 取消。
- 如果新键已被其他动作占用，两个动作会自动交换键位，不会出现冲突。
- 「恢复默认」一键还原全部键位。
- 设置保存在浏览器 `localStorage`（键名 `dust2.bindings.v1`），刷新或下次打开仍然生效；
  开始界面、底部提示条和 HUD 会同步显示当前键位。

鼠标左键射击、鼠标右键转向和 Esc 暂停是固定键位，不参与自定义。

## 开局设置：难度与敌人数

开始界面在「进入战场」上方提供两组选项，选择会保存在本机（`localStorage` 键 `dust2.prefs.v1`），
下次打开仍然是上次的选择：

| 难度 | 敌人表现 |
| --- | --- |
| 简单 | 命中率低、反应慢（0.8s）、伤害 ×0.65、移动较慢、视野 28m |
| 普通 | 标准交火手感：命中率 62%、伤害 ×1.0、视野 38m |
| 困难 | 命中率 80%、伤害 ×1.35、射速更快、移动更快、视野 46m |

敌人数量可选 **3 / 6 / 9**：3 人时分布在中路与 A、B 两区，6 人为标准配置，9 人会在 A 小、
中门、B 连接额外增援。人数会同步显示在任务目标与开始界面说明里。

## 玩法

- 生命值 100，被击中扣血，归零任务失败。
- 清除当前难度下全部敌人即胜利，HUD 显示剩余敌人、击杀数、血量、弹药。
- 敌人具备巡逻、警戒、追踪、射击、死亡五种行为，会利用掩体与视线。
- 地图包含 T 出生点、中路、A 大通道、A 包点、A 小道、B 洞、B 包点、CT 出生点，
  墙体、木箱、矮墙、斜坡均有碰撞，玩家不可穿墙。
- 爆头伤害 120、躯干 36、腿部 24，一枪爆头可直接击杀。

## 地图

`js/world/map.js` 里的 de_dust2 简化版包含 10 个功能区域，并按 Dust 系列的经典配色布置掩体：

| 区域 | 特点 |
| --- | --- |
| T 出生点 | 开局位置，四周有沙袋与木箱 |
| 中路 | 南北贯通的中轴通道，两侧有门框与斜坡 |
| A 大通道 | 连接中路与 A 包点的主通道，北口有拱门与入口高台坡道 |
| A 小道 | 从中路绕到 A 侧的近道，入口有门框 |
| A 包点 | 三面环绕的箱位掩体 |
| B 洞 | 通往 B 侧的隧道，入口上坡 |
| B 通道 | 串联 B 洞与中路的横向通道 |
| B 包点 | 三面环绕的箱位掩体 |
| CT 出生点 | 防守方出生区域，北侧有拱门 |

- **掩体**：38 个木箱、14 个油桶、矮墙、沙袋堆，全部带 AABB 碰撞体。
- **门框拱门**：5 座石拱门作为区域之间的视觉地标（A 大通道、中路、B 洞、CT、A 小道）。
- **斜坡**：A 大通道入口高台与 B 洞上坡，坡道两侧有挡墙实体，不会从边缘走空。
- **自然与远景**：12 块岩石、12 棵棕榈树、3 个集装箱、7 座远景沙丘。
- 小地图（右上角）会标出区域名称，方便判断自己所在位置。

## 画面与性能

- **黄昏沙漠光照**：程序化天空盒（渐变 + 云带）、低角度斜阳、暖色主光 + 冷色补光，
  远处有沙尘雾和起伏山丘，近处有棕榈树、油桶、集装箱等装饰。
- **静态合批**：墙体、木箱、掩体、装饰全部按材质合并成少数几个网格，
  draw call 从几十降到个位数；颜色靠顶点色区分，材质表保持个位数。
- **对象池**：曳光弹、命中碎屑、血雾、弹孔全部预分配，战斗时零 GC 压力。
- **敌人合模**：每个敌人由 9 个网格压成 2 个（躯干 / 头），9 名敌人共用一份材质。
- **自适应画质**：连续 45 帧均值低于 42fps 自动降档（像素比 1.75 → 1.25 → 1，
  阴影贴图 2048 → 1024 → 512），高于 57fps 再逐级升回，弱机也能流畅运行。
- 调试接口 `window.__dust.quality` 可查看当前画质档位（0 低 / 1 中 / 2 高）。

## 注意

- 游戏首次打开需要联网从 CDN 加载 Three.js（unpkg，失败会自动尝试 jsdelivr / esm.sh）。
- 建议使用 Chrome / Edge / Firefox 最新版，窗口尺寸 1280×720 以上。
- 在地址后加 `?auto=1` 可跳过开始界面直接进入游戏（便于截图或演示）。
